# KATAMAR Fashion — E-Commerce Website

A modern, luxury fashion e-commerce storefront built with vanilla HTML, CSS, and JavaScript.

## 🌟 Features

- **Responsive design** — works on mobile, tablet, and desktop
- **Product catalog** with category filtering (Tops, Bottoms, Outerwear, Accessories)
- **Shopping cart** with slide-out drawer, add/remove items, and live total
- **Custom animated cursor** with smooth lag effect
- **Animated hero section** with floating gradient shapes
- **Infinite marquee** ticker
- **Lookbook section** with editorial layout
- **Newsletter signup** with validation
- **Toast notifications** on cart actions
- **Sticky nav** that changes on scroll

## 🛠 Technologies Used

- HTML5 (semantic markup)
- CSS3 (custom properties, flexbox, grid, animations, responsive design)
- Vanilla JavaScript (DOM manipulation, event handling, state management)
- Google Fonts (Cormorant Garamond + Barlow)

## 🚀 How to Run

1. Clone this repository
2. Open `index.html` in your browser
3. No build tools or dependencies needed!

```bash
git clone https://github.com/YOUR_USERNAME/katamar.git
cd katamar
open index.html
```
